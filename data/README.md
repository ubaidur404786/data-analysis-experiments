# Datasets

Small copies of public datasets, saved here so every notebook runs offline.

| File | Rows | Source | Licence | Used in |
|---|---|---|---|---|
| `tips.csv` | 244 | [seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/tips.csv), from Bryant & Smith (1995), *Practical Data Analysis: Case Studies in Business Statistics* | Teaching dataset, no formal licence stated | Statistics 01, 02, 05, 06, 08 · Experimentation 03 |
| `galton_heights.csv` | 934 | [Rdatasets](https://vincentarelbundock.github.io/Rdatasets/csv/HistData/GaltonFamilies.csv), R package `HistData`, collected by Francis Galton (1886) | Historical data (public domain). `HistData` is GPL | Statistics 03, 05, 08 |
| `titanic.csv` | 891 | [seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv), same passengers as the Kaggle Titanic training set | Historical records, free for teaching | Statistics 04, 06, 08 · Experimentation 03 |
| `penguins.csv` | 344 | [seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/penguins.csv), from [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/) (Gorman, Williams & Fraser, 2014) | CC0 | Statistics 07, 09 · Experimentation 03 |
| `horse_kicks.csv` | 280 | [Rdatasets](https://vincentarelbundock.github.io/Rdatasets/csv/pscl/prussian.csv), R package `pscl`, from von Bortkiewicz (1898) | Historical data (public domain). `pscl` is GPL | Statistics 08 |
| `cookie_cats.csv` | 90,189 | Mobile game A/B test by Tactile Entertainment, published by DataCamp and on [Kaggle](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing). Copy from a [GitHub mirror](https://github.com/ryanschaub/Mobile-Games-A-B-Testing-with-Cookie-Cats) | Shared publicly for learning, no formal licence stated | Statistics 08 · Experimentation 01, 02 |
| `sleep.csv` | 20 | [Rdatasets](https://vincentarelbundock.github.io/Rdatasets/csv/datasets/sleep.csv), R's built-in `sleep` data, Cushny & Peebles (1905) | Public domain | Experimentation 03 |
